## 2025-04-19 - Added ARIA labels to dynamically created elements
**Learning:** In vanilla JavaScript applications where UI elements are created dynamically via `document.createElement`, standard static HTML parsing for accessibility doesn't always apply out-of-the-box in the same way component-based frameworks (like React/Vue) might enforce or make it obvious. Consequently, properties like `aria-label` must be explicitly assigned using `.setAttribute('aria-label', ...)` to ensure that dynamically added, icon-only buttons remain accessible to screen readers.
**Action:** When working on vanilla JS frontends, always review dynamic DOM construction sections to ensure that any interactable elements, particularly icon-only buttons, have explicit `setAttribute` calls for ARIA attributes and titles.
