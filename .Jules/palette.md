## 2025-02-23 - Accessibility for Dynamically Created DOM Elements
**Learning:** When dynamically creating DOM elements using vanilla JavaScript (e.g., via `document.createElement()`), ARIA attributes such as `aria-label` and general attributes like `title` must be explicitly assigned using `setAttribute()`. Setting them just through properties like `element.ariaLabel` does not always work reliably or may be missed by screen readers. This ensures icon-only buttons remain accessible and usable, bypassing static HTML parsing.
**Action:** Always use `element.setAttribute('aria-label', 'Description')` and `element.setAttribute('title', 'Description')` when constructing icon-only UI elements dynamically in JS to ensure screen readers provide context and users see tooltips on hover.
