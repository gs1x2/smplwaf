## 2024-05-19 - Vanilla JS ARIA Attributes and Focus-Within
**Learning:** When dynamically creating DOM elements in vanilla JavaScript (e.g., via `document.createElement`), ARIA attributes such as `aria-label` must be explicitly assigned using `setAttribute()`. This ensures icon-only buttons remain accessible to screen readers, as they bypass static HTML parsing. Additionally, when hiding interactive elements like buttons, using `opacity: 0` alongside `.parent:focus-within { opacity: 1 }` is better for keyboard accessibility than `display: none`, as it allows keyboard users to tab onto the hidden elements and make them visible.
**Action:** Always use `setAttribute('aria-label', ...)` on dynamically created JS buttons without clear text. Prefer `opacity` over `display: none` for hidden controls to allow keyboard focus.
