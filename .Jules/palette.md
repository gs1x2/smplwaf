## 2024-05-04 - Accessible Dynamically Rendered Hidden Controls
**Learning:** In vanilla HTML/JS applications, using `display: none` for hover-only controls (like `.file-controls`) completely breaks keyboard navigation as the elements are removed from the accessibility tree and cannot be focused. Additionally, when creating icon-only buttons dynamically via `document.createElement()`, ARIA attributes like `aria-label` must be explicitly assigned using `.setAttribute()` since static HTML attributes aren't parsed.
**Action:** Replace `display: none` with `opacity: 0` and `pointer-events: none` on the container, and use `:hover` along with `:focus-within` to restore visibility (`opacity: 1`, `pointer-events: auto`). Always use `.setAttribute('aria-label', ...)` on dynamically created icon buttons.
